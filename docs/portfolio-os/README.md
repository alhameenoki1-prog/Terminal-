# Portfolio OS — Board-Level Research Package

Research, design, review and decision package for the founder's financial-intelligence platform, produced 2–4 November 2026 by a virtual multidisciplinary team run as separate specialist agents. **No application code has been written.** Start with Document 12.

## Read in this order

1. `12_final_executive_recommendation.md` — the recommendation, the decisions only the founder can make, and the facts needed.
2. `11_independent_red_team_review.md` — the strongest criticism of the plan.
3. `decisions/INVESTMENT_COMMITTEE_MEMO.md` — decisions D1–D9 with votes and dissents.
4. `10_engineering_and_product_roadmap.md` — the build plan.

## Standing caveats

- Every specialist, reviewer and committee member is a simulated role. None is a licensed accountant, tax practitioner, lawyer or regulated adviser. Items needing licensed sign-off are listed in Document 6 §9 and Document 12 §7.
- All worked examples use synthetic data. No real financial data was used.
- Time-sensitive facts were checked between 2 and 4 November 2026 and carry those dates.
- The founder's earlier conversations were not accessible; Document 1 §10 lists the assumptions made instead.
